# Modern Flappy Bird Assets

A modern, smooth 3D-cartoon style asset sheet for a Flappy Bird-inspired game.

## Contents

- `assets/modern-flappy-bird-sprite-sheet.png` — sprite-sheet concept with three bird poses, green pipes, sky background, ground strip, coin, score display, and replay button.

The image is a concept sheet rather than a set of production-ready sprites. Crop the elements into individual transparent images before importing them into a game engine.

## Source inspiration

The visual direction was inspired by [samuelcust/flappy-bird-assets](https://github.com/samuelcust/flappy-bird-assets). This sheet is a modern reinterpretation and is not the original pixel-art asset pack.
